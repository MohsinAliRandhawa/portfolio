# Mohsin Ali Randhawa —  Portfolio 🛡️

Welcome to the source code for my personal portfolio website! This project is designed with a dark, glassmorphic aesthetic to reflect my focus on **Cloud Security**, **DevSecOps**, and **Python Automation**.

## 🌐 Live Demo
https://mohsinalirandhawa.vercel.app

## 🚀 Technologies Used
* **HTML5:** Semantic structure for optimal SEO and accessibility.
* **CSS3:** Custom properties (variables), Flexbox/Grid layouts, glassmorphism, glowing neon borders, and advanced animations (no external CSS frameworks).
* **JavaScript (Vanilla):** 
  * Matrix Rain Canvas Effect
  * Particle Network Background
  * Typing Animation
  * IntersectionObserver for Scroll Reveals
  * 3D Tilt Effect on Project Cards

## 📂 Project Structure
* `index.html`: The main single-page portfolio.
* `style.css`: The "CyberShield" design system (colors, layout, animations).
* `script.js`: Interactive JavaScript engine.
* `assets/`: Contains images such as the profile photo.

## 💻 Local Development
This is a static website. To view it locally, you can simply open `index.html` in your web browser. 

For the best experience (to avoid CORS issues with certain JS features if added later), run a local server:
```bash
# Using Python
python -m http.server 8080

# Or using Node.js
npx serve
```
Then visit `http://localhost:8080` in your browser.
